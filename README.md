# Estudos — MBA Data Science e Analytics (USP/Esalq)

**Site de estudo** (navegação, busca, flashcards, autoteste e plano com checklist): https://victorantunes.github.io/mba-ds-estudos/

## Conteúdo do repositório

- [plano_de_estudos.md](plano_de_estudos.md) — plano de 33 dias, método de estudo e prioridades
- [resumos/](resumos) — 30 resumos, um por disciplina: conceitos, fórmulas, comparativos e a seção "Pergunta típica"
- `docs/` — código do site (gerado por `tools/build_site.py`)
- `MATERIAIS.md` — índice dos materiais das aulas (slides, planilhas, scripts), sem vídeos

Para regenerar o site depois de editar um resumo: `pip install markdown && python tools/build_site.py`.
